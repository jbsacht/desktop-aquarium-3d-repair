This repository contains the independently written compatibility library,
local patching/build tools, tests and documentation. It does not contain the
original Desktop Aquarium 3D source code, executable, fish models, textures,
icons, nibs, receipts, or any user's photographs.

Desktop Aquarium 3D / Something Fishy! is the original application by Robert
Bennett / Useless Creations. Its code, assets and names remain with their
respective owners. This is an unofficial compatibility project.

The MIT license covers this repository's new repair code, tools, tests and
text. It does not grant rights to the original application or to generated
app bundles. Users must provide their own original app locally. Do not upload
original or repaired app bundles to this repository or its releases.

The patcher contains only short expected instruction sequences needed to
verify and apply the documented modifications, plus a SHA-256 fingerprint.
There are no original executable files, disassembly dumps or decompiled sources.

The OpenGL surface-lifecycle approach was informed by this public Ouzel fix:
https://github.com/elnormous/ouzel/commit/7e708636189d970bad6b013ecd5375cfe693f3f3
No Ouzel source files are bundled here.
